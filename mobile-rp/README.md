# NYX Roleplay v4 — Mobile RP Visual

Esta versão melhora a apresentação visual do protótipo que rodou no Android:
- menu inicial;
- criação/entrada com nome;
- cidade com blocos urbanos, calçadas e marcações;
- prédios com faixas de janelas;
- iluminação urbana;
- Polícia, Hospital, Prefeitura e NyxStore;
- veículo 3D simples com motor/combustível;
- HUD mobile;
- minimapa visual;
- botões de correr, pular, carro e celular;
- personagem 3D;
- sistemas da v2 preservados no projeto.

É um protótipo jogável e visual, não um cliente GTA/RP de produção. Modelos humanos, carros, animações e assets finais ainda podem substituir os objetos procedurais.

Para testar: abra `project.godot` no Godot Android e execute.
