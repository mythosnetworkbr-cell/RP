# MYTHØS RP — Cache GTA

O cache recebido foi preparado para instalação pelo launcher em:

`/storage/emulated/0/GTA/`

## Arquivo recebido

`MythosNetworkSAMP.zip`

## Arquivo preparado

`MythosNetworkSAMP-GTA.zip`

O arquivo preparado remove a pasta externa `MythosNetworkSAMP/` do ZIP. Assim, quando o launcher extrair o conteúdo para `/storage/emulated/0/GTA/`, as pastas `SAMP`, `data`, `models`, `audio`, `texdb` etc. ficam no nível correto para o cliente.

Servidor configurado: `51.68.107.75:10961`.

> O arquivo enviado nesta conversa é um cache do jogo. Ele não contém um APK Android; o APK do cliente precisa ser gerado/publicado pelo workflow de cliente do projeto.
